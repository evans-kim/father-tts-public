말하기 도우미 iOS 개인정보처리방침

최종 수정: 2026-10-19

기본 이용과 기기 내 저장

말하기 도우미 iOS 앱은 회원가입, 로그인, 광고, 분석 도구를 사용하지 않습니다.

앱은 사용자가 입력한 자주 쓰는 문구, 대화 기록, 음성 설정을 기기 내부에 저장합니다. MiniMax API 키는 iOS Keychain에 이 기기 전용으로 저장하며 다른 기기로 동기화하지 않습니다. iOS 기기 백업 설정에 따라 문구, 기록, 설정은 백업될 수 있습니다.

MiniMax 선택 기능

사용자가 MiniMax 음성을 사용하면 읽기를 요청한 문장과 MiniMax API 키가 MiniMax 서버로 직접 전송됩니다. 보이스 클로닝을 요청하면 직접 선택한 음성 파일도 MiniMax 서버로 전송됩니다. 앱 개발자 서버로는 전송되지 않습니다.

MiniMax는 전송된 입력과 결과물을 자체 정책에 따라 처리·보관할 수 있으며 미국의 데이터 센터를 이용한다고 안내합니다. 보관 기간과 삭제 요청 방법은 MiniMax API 개인정보처리방침을 확인하세요.

생성 음성 파일 관리

생성된 MiniMax 음성 파일과 관련 문장·목소리·모델·예상 사용액 정보는 앱 내부 저장소에 보관되고 기기 백업에서 제외됩니다. 설정한 저장 용량을 넘으면 오래된 파일부터 자동으로 삭제됩니다. 사용자는 음성 파일과 개별 대화 기록을 앱 안에서 삭제할 수 있습니다. API 예상 사용액은 앱이 계산한 참고값이며 MiniMax 계정의 실제 결제액과 다를 수 있습니다.

추적 및 문의

앱은 광고 또는 사용자 추적 기능을 사용하지 않습니다. iPhone 기본 음성을 사용하는 동안 문장과 음성 파일은 MiniMax로 전송되지 않습니다.
