말하기 도우미 iOS 지원

말하기 도우미는 입력한 문장을 iPhone 음성으로 읽고, 자주 쓰는 문구와 대화 기록을 기기에 저장합니다.

자주 묻는 질문

MiniMax API 키가 필요한가요?

아니요. iPhone 기본 음성은 API 키 없이 사용할 수 있습니다. MiniMax 음성 및 보이스 클로닝을 선택할 때만 사용자의 MiniMax API 키가 필요합니다.

MiniMax 기능의 이용 연령은 어떻게 되나요?

MiniMax 계정과 API 이용에는 MiniMax의 약관 및 개인정보처리방침이 적용됩니다. MiniMax는 16세 미만에게 해당 서비스를 이용하지 말라고 안내합니다. 기기 기본 음성은 MiniMax 계정 없이 사용할 수 있습니다.

MiniMax 사용액이 표시된 값과 다른 이유는 무엇인가요?

앱에 표시되는 값은 요청 문자 수를 이용한 예상액입니다. 실제 요금과 크레딧은 MiniMax 계정에서 확인하세요.

문구와 기록을 다른 기기로 옮길 수 있나요?

앱은 Android와 iOS 간 자동 이전이나 동기화를 제공하지 않습니다. 각 기기의 저장 공간과 백업 설정에 따라 데이터가 관리됩니다.

저장된 음성 파일은 어떻게 지우나요?

설정의 ‘MiniMax 음성 파일’ 화면에서 개별 파일을 삭제할 수 있습니다. 저장 용량 한도를 넘으면 오래된 파일부터 삭제됩니다.
